# 独立验证与验收

## 验收分层

1. **静态检查**：文件存在、格式正确、Schema 和导出符号符合约定。
2. **单元测试**：验证单个函数和边界条件。
3. **集成测试**：验证模块间真实接口、注册、生命周期和错误传播。
4. **宿主验收**：在目标 DSH 版本与真实 Profile 中加载、调用和卸载。
5. **交付验收**：检查构建产物、安装路径、版本、日志和可复现步骤。

## 证据要求

- 每项结论都对应可观察证据：命令输出、测试结果、CI Run、文件内容或宿主日志。
- 明确记录提交 SHA、分支、运行环境和测试范围。
- 失败测试不能从摘要中省略。
- 未执行的测试标记为“未运行”；模拟测试不得标记为真实宿主通过。
- CI 通过仅证明该 CI 工作流覆盖的检查通过。

## 最终状态

使用以下状态之一：
- **通过**：验收条件全部满足且证据可核验。
- **部分通过**：部分条件满足，列明剩余项。
- **失败**：关键条件未满足。
- **未验证**：缺少必要环境或证据。

## 完成声明

只有在交付物存在、关键测试通过、目标环境验证完成且限制已披露后，才能声明完整交付。
